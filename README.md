# FatFish public animation assets

12 FFM1 animation packs and six two-action manifests for a personal ESP32 prototype.

No firmware credentials, Wi-Fi settings, recordings or chat data are included.

The ESP32 downloads while idle, validates CRC32 and plays from a two-slot LittleFS cache. Rotation is on-device.

This is an unofficial learning prototype, not affiliated with DeepSeek. Character rights remain with their respective owners.
